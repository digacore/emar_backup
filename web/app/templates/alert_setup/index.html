Alert Setup

Alert Types

eMAR Vault sends the following alerts when devices or locations go offline:

  • Critical alert – When an entire location is offline (all computers at that location)
  • Primary computer down – When the primary backup computer at a location has been offline for more than 3 hours
  • Alternate computer down – When an alternate backup computer has been offline for more than 3 hours
  • Daily / Weekly / Monthly summaries – Periodic reports of offline devices
Configure Who Receives Alerts

Control alert delivery from these pages:

  • User settings – Enable or disable "Receive Alerts emails" per user (Company/Location admins)
  • Computer list – Pause alerts for specific computers (e.g. during maintenance)
Support Emails (Global Admins)

These emails receive all offline alerts (critical, primary, alternate) in addition to company/location recipients. Use comma-separated values. Leave empty to use the ALERT_SUPPORT_EMAILS environment variable.
